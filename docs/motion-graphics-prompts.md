# モーショングラフィックスを頼むときのプロンプト集

mirage-mcp に新しい作品を作らせるときのテンプレート。`［ ］` を埋めて使う。どれも、テンポと尺・色の数・動きのルール・技法・仕上がりの確かめ方を項目にしてある。

普段は **A**、方向性を探りたいときは **B** で数を出す。

## A. 詳細ブリーフ型（品質がいちばん安定する）

```
Mirage Composerで新しいモーショングラフィックスを作って、［保存先］.mcompに保存して。

■ コンセプト：［一言で。例：呼吸するタイル／重力で落ちる図形］
■ 雰囲気：［形容詞を3つ。例：ポップ・シンプル・モダン］
■ 尺とテンポ：［BPM○○で1小節ごとに展開／BPMなし・○秒でループ］
■ 構成：［例：4シーン×1小節、最後のシーンが最初につながってループ］
■ 配色：背景［黒］、色は［○色まで。例：ピンク・イエロー・シアン・白］
■ 動きのルール：
  - イージング：［例：expo-outで止まる瞬間にキレ、back-outで弾む］
  - 時間差：［例：要素ごとに少しずつずらす］
  - 余白：［例：画面の○割は空ける、詰め込みすぎない］
■ 技法：［Iterator中心／Metal Shader中心／おまかせ］
■ 文字：［なし／小さいラベルのみ／タイトルを大きく］
■ NG：［例：グラデーション多用、グロー、文字だらけ］

各シーンを描画して確認し、気になる点を直してから保存して。最後に構成と調整ポイントを短く説明して。
```

## B. ミニマル型（試作を早く回す）

```
［コンセプト］のモーショングラフィックスを作って。
［BPM○○／自由テンポ］、背景［黒］、［ポップ／静か／クール］な感じ。
技法は［Iterator／シェーダー／おまかせ］。［保存先］に保存。
```

決まっていない部分は AI が判断するので、毎回違う方向性が出る。数を出して選ぶのに向く。

## C. リファレンス・ムード型（作風を寄せる）

```
次のような作風で、新しいモーショングラフィックスを作って。

■ 参考にしたい作風：［例：スイスデザインのポスターが動く感じ／
  Apple製品紹介のミニマルさ／90年代のメンフィス柄］
■ 寄せたい点：［例：太い幾何学形、大胆な余白、限られた色数］
■ 寄せなくていい点：［例：写真やロゴは使わない］
■ 見る人に感じてほしいこと：［例：気持ちいいリズム感／ずっと見ていられる］
■ 条件：［BPM・尺・背景・保存先］

まず作風の解釈を3行で書いてから作り始めて。
```

最初に解釈を書かせるので、作る前に方向のずれに気づける。

## D. 技法チャレンジ型（Mirage の機能を掘る）

```
［機能名：Iterator／Render In Image／Particle System／Queue／3D Transformation など］
を主役にしたモーショングラフィックスを作って。

■ その機能でしかできない見せ方を1つ核にする：［例：フィードバックの残像、
  何百個もの要素の群れ、奥行きのあるカメラワーク］
■ 動きの性格：［規則的／ランダムで有機的／その中間］
■ 条件：［BPM・尺・背景・配色・保存先］

使えない機能やMCPの不具合を見つけたら、作品を作り終えたあとにまとめて報告して。
```

作品づくりと mirage-mcp のテストを兼ねる。Multiplexer の設定の不具合（e698ea2 で修正）も、この種の作業で見つかった。

## どの型にも足せる一文

- 「プロのモーションデザイナーが見ても納得する仕上がりで」：イージングや間の作り込みが増える。
- 「動きは"溜め→動く→止まる"のメリハリを意識して」：のっぺりした動きを防ぐ。
- 「要素は少なく、1つ1つの動きを丁寧に」：詰め込みすぎを防ぐ。
- 「〇秒・〇秒・〇秒の静止画で確認してから保存して」：見せ場のタイミングを指定できる。
- 「2案作って比べさせて」：方向性で迷っているときに。
